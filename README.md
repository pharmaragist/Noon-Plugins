# Noon Plugins

Hosted plugin repository for [Noon](https://github.com/pharmaragist/Noon) — the Quickshell desktop shell for Hyprland.

Plugin sources in this repo are packed into installable `.zip` archives and an index (`plugins.json`) by GitHub Actions, then published to the `dist` branch so they can be browsed and installed from the Noon **Store**.

## How it works

`main` is source-only. Every push to `main` that touches plugin sources, assets, or the bundler re-runs the bundle workflow, which generates the installable artifacts and force-pushes them to `dist`.

| Branch | Contents | Purpose |
|---|---|---|
| `main` | `plugins/`, `assets/`, `tools/`, workflow | source of truth — never contains generated artifacts |
| `dist` | `plugins.json` + `zip/<group>/<slug>.zip` | generated output consumed by Noon |

- `plugins/<group>/<slug>/` is the only thing you ever edit.
- `plugins.json` and `zip/` are generated by `tools/bundle_all.sh` and are **gitignored** — do not commit them.
- The hub index lives at `https://raw.githubusercontent.com/pharmaragist/Noon-Plugins/dist/plugins.json`.

## Layout

```
Noon-Plugins/
├── plugins/                     # source of truth: one dir per plugin
│   ├── beam/                    #   intersheller, tldr, trans
│   ├── dock/                    #   media
│   ├── sidebar/                 #   deen, MaterialSymbols, NVU, Scrcpy, Sokoun, Syncthing
│   └── widgets/                 #   screen-time, sticky-notes
├── assets/thumbs/<group>/<slug>.png   # optional 1:1 preview thumbnail
├── tools/
│   ├── bundle_all.sh            # pack zips + regenerate plugins.json
│   └── create_new_plugin.sh     # interactive plugin scaffolder
├── .github/workflows/bundle.yml # CI: rebuild dist on push to main
├── LICENSE
└── README.md
```

A plugin is a directory `plugins/<group>/<slug>/` containing a `manifest.json` and its QML files. The `slug` (directory name) becomes the hub `id` in `plugins.json`.

## Adding a plugin

### 1. Scaffold (optional)

```sh
PLUGINS_DIR=plugins ./tools/create_new_plugin.sh
```

Prompts for group, name, maintainer, description and version, then creates `plugins/<group>/<Name>/manifest.json` and `<Name>.qml` with the right group stub.

### 2. Or write it by hand

```
plugins/<group>/<slug>/
├── manifest.json
└── Entry.qml
```

Minimal manifest:

```json
{
  "name": "My Plugin",
  "pluginGroup": "sidebar",
  "mentainer": "you",
  "version": "1.0",
  "description": "What it does",
  "icon": "star",
  "entry": "@plugins/Entry.qml",
  "singletons": []
}
```

`entry` points at a QML file inside the plugin dir (`@plugins/` is rewritten to the plugin's install location at runtime). Files listed in `singletons` are registered as QML singletons (use for backing services).

### 3. Push

Push to `main`; CI repacks everything and republishes `dist` automatically. Add an optional thumbnail at `assets/thumbs/<group>/<slug>.png` (missing thumbnails just produce a bundler warning).

In Noon dev mode, plugin changes hot-reload on file save.

## Plugin groups

| Group | Where it loads | Root component | Notes |
|---|---|---|---|
| `sidebar` | left sidebar item | `SidebarItemContainer` | `baseSize`/`expandSize`, `detachable`, `incubatable`, `searchable` |
| `widgets` | desktop widget | `WidgetContainer` | sized variants `small`/`normal`/`large`/`xlarge` |
| `dock` | bottom dock tile | `StyledRect` | `direction` chooses which side the popup opens |
| `beam` | command palette beam | — | **manifest-only**: driven by `hinter`/`executor`, no entry QML is loaded |

## Manifest reference

Common fields:

| Field | Type | Meaning |
|---|---|---|
| `name` | string | display name (required) |
| `pluginGroup` | string | `sidebar`, `widgets`, `dock` or `beam` |
| `id` | string | optional extra id (hub id stays the directory name) |
| `mentainer` / `maintainer` | string | author (the typo is historical; both are accepted) |
| `version` | string | e.g. `1.0` |
| `description` | string | one-liner shown in the store |
| `icon` | string | Material Symbols icon name |
| `enabled` | bool | load at startup |
| `entry` | string | `@plugins/<File>.qml` — the entry component |
| `singletons` | string[] | extra `.qml` files registered as singletons |
| `pythonRequirements` | string[] | pip packages installed into the Noon venv when the plugin is enabled |

Group-specific:

- **sidebar**: `shape` (`Cookie12Sided`, `Slanted`, …), `expandable`, `detachable`, `incubatable`, `searchable`, `baseSize`, `expandSize`
- **widgets**: `expandable`
- **dock**: `direction` (`left`/`right`)
- **beam**: `prefix`, `icon`, `shape`, `placeholder`, `showHint`, `showOsrButton`, `hinter`, `executor`

## Regenerating locally

`tools/bundle_all.sh` is the same generator CI uses:

```sh
./tools/bundle_all.sh            # pack zips + write plugins.json
./tools/bundle_all.sh --no-zip   # only plugins.json
./tools/bundle_all.sh --no-index # only zips
./tools/bundle_all.sh --clean    # wipe zip/ first
```

Requires `jq` and `zip`. Environment: `PREVIEW_BASE` (default `…/main`), `DOWNLOAD_BASE` (default `…/dist`), `RAW_BASE` (sets both). Output is deterministic (`LC_ALL=C`).

**Important:** archives pack the plugin's *contents* at the zip root — `manifest.json` must sit one level deep at most. Noon's installers (the Go `store-service` and `plugins_helper.sh`) locate the manifest near the archive root and nothing else tolerates deeper nesting.

## Consuming the repo

Add the provider to `~/.noon/user/store-providers.json`:

```json
{
  "static": [
    {
      "id": "noon-plugins",
      "name": "Noon Plugins",
      "index": "https://raw.githubusercontent.com/pharmaragist/Noon-Plugins/dist/plugins.json"
    }
  ]
}
```

Each index entry links `download` → the zip on `dist` and `preview` → the thumbnail on `main`.
